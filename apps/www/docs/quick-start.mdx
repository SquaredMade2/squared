# Quick Start Guide

Welcome to Squared! This Quick Start Guide will help you set up your account and start managing your tasks in no time.

## Prerequisites

Before you begin, make sure you have:
- A valid email address
- Access to a web browser (Chrome, Firefox, Safari, etc.)
- Basic understanding of task management concepts

## Getting Started

Follow these simple steps to start using Squared:

### 1. Sign Up

If you haven't already, [sign up](/docs/sign-up) for a Squared account. Click on the "Sign Up" button on the homepage and fill in your details.

### 2. Create Your First Project

Once logged in:
1. **Create Workspace Prompt**: A "Create Workspace" pop-up will appear automatically after you log in.
2. **Enter Workspace Name**: Type in a name for your workspace.
3. After entering the workspace name, you will be redirected to your newly created workspace's URL.
4. **Dashboard Overview**: You will immediately see your workspace dashboard, which will initially display no tasks.

### 3. Add and Assign Tasks

Start adding tasks to your workspace:
1. **Open New Issue Modal**: Click the **+ Add your first task** button on your dashboard to open the **New Issue Modal**.
2. **Fill in Task Details**:
   - **Title**: Enter a concise title for your task.
   - **Description** (optional): Provide more details about the task.
   - **Status**: Select the task status (e.g., To Do, In Progress).
   - **Labels**: Add relevant labels to categorize the task.
   - **Priority**: Set the priority level (e.g., Low, Medium, High).
   - **Effort Estimate**: Estimate the effort required to complete the task.
   - **Due Date**: Choose a deadline for the task.
3. **Create Task**: Click the **Create Issue** button to add the task to your dashboard. If you need to cancel, click **Discard**.
