# Slot Component

## Overview

The Slot component is a powerful utility for component composition in React. It allows for flexible content insertion and prop merging, making it easier to create reusable and customizable components.

## Core Components

### Slot

The `Slot` component serves as a specialized wrapper that intelligently merges props between a parent component and its child. It enables component polymorphism by allowing a component to render as different elements while maintaining consistent behavior and styling.

Key features:
- Intelligent prop merging (event handlers, styles, classNames)
- Ref forwarding and composition
- React.Fragment compatibility for React 19

### Slottable

The `Slottable` component indicates which part of a component's children should be treated as replaceable content. It marks specific parts of a component's structure that can be overridden when used with the `asChild` pattern.

Unlike `Slot` which handles the prop merging and component substitution, `Slottable` simply marks content as eligible for replacement.

## Difference between Slot and Slottable

- **Slot**: Handles the actual component replacement and prop merging mechanism. It's responsible for cloning elements and ensuring props are correctly merged between the parent and child components.

- **Slottable**: Acts as a marker for content that should be replaceable. It doesn't perform any transformations itself but identifies which parts of your component children should be replaced when used with `Slot`.

Think of `Slot` as the engine that performs the component composition, while `Slottable` is a marker that tells the engine where to place specific content.

## Installation

To use the Slot component, ensure you have the necessary dependencies installed in your project:

```bash
npm install @squaredmade/ui
```

## Usage

Here's a basic example of how to use the Slot component:

```jsx
import { Slot } from '@squaredmade/ui/slot';

function Button({ children, ...props }) {
  return (
    <Slot {...props}>
      <button>{children}</button>
    </Slot>
  );
}

// Usage
function App() {
  return (
    <Button className="custom-class" onClick={() => console.log('Clicked!')}>
      Click me
    </Button>
  );
}
```

## API

### Slot

The main component for creating slottable content.

#### Props

- `children`: React.ReactNode
  - The children to be rendered within the Slot.
- All other props are passed to the slotted element.

### Slottable

A component used to wrap children that should be treated as slottable content.

#### Props

- `children`: React.ReactNode
  - The children to be treated as slottable content.

### createSlot / createSlottable

Utility functions to create custom Slot and Slottable components with custom display names.

## Advanced Usage

### Using Slottable

The `Slottable` component allows for more precise control over which children can be slotted:

```jsx
import { Slot, Slottable } from '@squaredmade/ui/slot';

function ComplexButton({ children, icon, ...props }) {
  return (
    <Slot {...props}>
      <button>
        {icon}
        <Slottable>{children}</Slottable>
      </button>
    </Slot>
  );
}

// Usage with default button
function App1() {
  return (
    <ComplexButton icon={<Icon />} className="custom-class">
      Click me
    </ComplexButton>
  );
}

// Usage with asChild to render as a link instead
function App2() {
  return (
    <ComplexButton icon={<Icon />} className="custom-class" asChild>
      <a href="/some-path">Click me</a>
    </ComplexButton>
  );
}
```

In this example, the `Slottable` component marks where `children` should be placed within the button structure, preserving the icon placement regardless of whether the component renders as a button or another element.

### Merging Props

The Slot component intelligently merges props:

- Event handlers are composed (both the slot's and the child's handlers will be called).
- Styles are merged.
- ClassNames are concatenated.
- Other props from the child override those from the slot.

## Best Practices

1. Use Slot when you want to create flexible, reusable components that can be easily customized.
2. Utilize `Slottable` when you need fine-grained control over which parts of your component can be replaced or extended.
3. Be mindful of prop merging behavior, especially for event handlers and styles.
4. Use TypeScript for better type safety when working with Slot components.
5. Create polymorphic components by using the `asChild` pattern with Slot.

## Accessibility

While the Slot component itself doesn't directly impact accessibility, it's important to ensure that the components you create using Slot follow accessibility best practices:

1. Preserve semantic HTML structure when using Slot.
2. Ensure that merged props don't override important accessibility attributes.
3. Test the resulting components with screen readers and keyboard navigation.
