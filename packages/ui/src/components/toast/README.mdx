# Toast Component System

## Overview

The Toast Component System is a comprehensive solution for displaying notifications in React applications. It provides a flexible and accessible way to show temporary messages to users, with features like swipe-to-dismiss, dynamic stacking, and keyboard navigation.

## Features

- Multiple toast types: success, error, info, warning, loading, and default
- Swipe-to-dismiss functionality with directional control
- Promise integration for async operation feedback
- Keyboard accessibility (Alt+T to focus, Escape to dismiss)
- Screen reader support with proper ARIA attributes
- Dynamic stacking with expandable toast list
- Mobile-responsive design with appropriate positioning
- Auto-dismiss with configurable duration
- Interactive pause on hover/focus

## Installation

To use the Toast Component System, ensure you have the necessary dependencies installed in your project:

```bash
npm install @squaredmade/ui
```

## Usage

Here's a basic example of how to use the Toast Component System:

```jsx
import { Toaster, toast } from '@squaredmade/ui/toast';

function App() {
  return (
    <>
      <button 
        onClick={() => toast.success('Operation completed successfully')}
      >
        Show Success Toast
      </button>

      <button 
        onClick={() => toast.error('An error occurred')}
      >
        Show Error Toast
      </button>

      {/* Place Toaster component at the root level */}
      <Toaster />
    </>
  );
}
```

### Using with Promises

```jsx
import { toast } from '@squaredmade/ui/toast';

function handleAsyncOperation() {
  const promise = fetch('/api/data');
  
  toast.promise(promise, {
    loading: 'Loading data...',
    success: (data) => `Successfully loaded ${data.length} items`,
    error: (err) => `Error: ${err.message}`
  });
}
```

### Advanced Configuration

```jsx
import { Toaster } from '@squaredmade/ui/toast';

function App() {
  return (
    <>
      <YourApp />
      
      <Toaster
        duration={5000}
        visibleToasts={3}
        gap={8}
        offset="24px"
        expand={false}
        closeButton={true}
        containerAriaLabel="Notifications"
        hotkey={["altKey", "KeyT"]}
      />
    </>
  );
}
```

## API

### Toaster Component

The container component that displays and manages toast notifications.

#### Props

<ArgTypes of={Toaster} />

### Toast API

The `toast` object provides methods for creating different types of notifications.

#### Basic Methods

- `toast(message, options?)` - Create a default toast
- `toast.success(message, options?)` - Create a success toast
- `toast.error(message, options?)` - Create an error toast
- `toast.info(message, options?)` - Create an info toast
- `toast.warning(message, options?)` - Create a warning toast
- `toast.loading(message, options?)` - Create a loading toast

#### Advanced Methods

- `toast.promise(promise, options?)` - Create toasts for promise lifecycle (loading, success, error)
- `toast.dismiss(id?)` - Dismiss a specific toast or all toasts if no ID is provided

#### Toast Options

- `id`: string | number - Custom identifier for the toast
- `type`: "success" | "error" | "info" | "warning" | "loading" | "default" - Toast type
- `icon`: React.ReactNode - Custom icon to override the default for the selected type
- `title`: React.ReactNode | (() => React.ReactNode) - Main toast content
- `description`: React.ReactNode | (() => React.ReactNode) - Secondary content
- `duration`: number - Time in milliseconds before auto-dismiss (0 or Infinity prevents auto-dismiss)
- `closeButton`: boolean - Whether to show a close button on this toast
- `dismissible`: boolean (default: true) - Whether this toast can be dismissed
- `action`: `{ label: React.ReactNode, onClick: (event) => void }` | React.ReactNode - Primary action
- `cancel`: `{ label: React.ReactNode, onClick: (event) => void }` | React.ReactNode - Secondary action
- `onDismiss`: (toast) => void - Callback fired when the toast is dismissed by user action
- `onAutoClose`: (toast) => void - Callback fired when the toast is auto-closed after duration

### useToasts Hook

Hook for accessing the toast state within components.

```jsx
import { useToasts } from '@squaredmade/ui/toast';

function Component() {
  const { toasts } = useToasts();
  
  return (
    <div>
      {toasts.length > 0 ? (
        <p>You have {toasts.length} active notifications</p>
      ) : (
        <p>No active notifications</p>
      )}
    </div>
  );
}
```

## Accessibility

The Toast Component System is designed with accessibility in mind:

- Proper ARIA attributes and roles throughout
- Keyboard navigation with clear focus management
- Support for screen readers with live region announcements
- Pause auto-dismiss when the user is interacting with a toast
- Visible focus indicators and proper contrast ratios
- Alternative text for icons and actions

## Best Practices

1. Keep toast messages concise and informative
2. Use appropriate toast types for different kinds of notifications
3. Set appropriate durations based on content length and importance
4. Provide clear actions when user interaction is required
5. Don't overuse toasts - reserve them for important information
6. Test with keyboard-only and screen reader users to ensure accessibility
