# Text Component

## Overview

The Text component is a flexible and customizable way to render text in React applications. It provides a wide range of styling options and supports responsive design, allowing developers to create consistent and visually appealing text across their applications.

## Features

- Customizable text size, weight, and color
- Support for text transformation and alignment
- Options for truncation and line clamping
- Configurable text decoration and line height
- White space handling options
- Responsive design support

## Installation

To use the Text component, ensure you have the necessary dependencies installed in your project:

```bash
npm install @squared/ui
```

## Usage

Here's a basic example of how to use the Text component:

```jsx
import { Text } from '@squared/ui/text';

function Example() {
  return (
    <Text size="lg" weight="bold" color="primary">
      Hello, world!
    </Text>
  );
}
```

## API

### Text

The main component for rendering styled text.

#### Props

- `size`: 'xs' | 'sm' | 'base' | 'lg' | 'xl' | '2xl' | '3xl' | '4xl'
  - Controls the font size of the text.
- `weight`: 'normal' | 'medium' | 'semibold' | 'bold'
  - Sets the font weight of the text.
- `transform`: 'normal' | 'uppercase' | 'lowercase' | 'capitalize'
  - Applies text transformation.
- `align`: 'left' | 'center' | 'right' | 'justify'
  - Sets the text alignment.
- `color`: 'foreground' | 'card' | 'popover' | 'primary' | 'secondary' | 'accent' | 'destructive' | 'muted'
  - Determines the color of the text.
- `decoration`: 'none' | 'underline' | 'line-through'
  - Applies text decoration.
- `lineHeight`: 'none' | 'tight' | 'snug' | 'normal' | 'relaxed' | 'loose'
  - Sets the line height of the text.
- `whiteSpace`: 'normal' | 'nowrap' | 'pre' | 'pre-line' | 'pre-wrap'
  - Controls how white space is handled.
- `truncate`: boolean
  - If true, truncates the text with an ellipsis.
- `clamped`: number
  - Limits the text to a specific number of lines.
- `className`: string
  - Additional CSS classes to apply to the text.

All props support responsive values, allowing you to specify different styles for different breakpoints.

## Customization

The Text component uses Tailwind CSS classes for styling. You can customize its appearance by providing your own classes through the `className` prop or by modifying the Tailwind configuration.

## Best Practices

1. Use consistent text styles throughout your application for better readability and visual harmony.
2. Consider accessibility when choosing text sizes and colors. Ensure sufficient contrast with the background.
3. Use the `truncate` or `clamped` props to handle long text in constrained spaces.
4. Leverage responsive props to adjust text styling for different screen sizes.
5. Use semantic HTML elements in conjunction with the Text component when appropriate (e.g., `<h1>`, `<p>`).

## Accessibility

When using the Text component, keep the following accessibility considerations in mind:

1. Ensure sufficient color contrast between the text and its background.
2. Use appropriate font sizes to maintain readability, especially on mobile devices.
3. Avoid using color as the only means of conveying information.
4. When using truncation or clamping, make sure important information is not hidden from screen readers.
