# Heading Component

## Overview

The Heading component is a flexible and customizable React component for rendering headings in your application. It's part of the @squaredmade/ui package and provides a consistent way to create headings with various levels, sizes, weights, and colors.

## Features

- Supports all HTML heading levels (h1 to h6)
- Customizable font size, independent of heading level
- Adjustable font weight
- Extensive color options, including theme colors and a zinc color scale
- Responsive text sizes for larger screens
- Accessible, using appropriate heading levels for document structure

## Installation

To use the Heading component, ensure you have the @squaredmade/ui package installed in your project:

```bash
npm install @squaredmade/ui
```

## Usage

Here's a basic example of how to use the Heading component:

```jsx
import { Heading } from '@squaredmade/ui/heading';

function MyComponent() {
  return (
    <Heading as="h1" size="4xl" weight="bold" color="primary">
      Welcome to My App
    </Heading>
  );
}
```

## Props

The Heading component accepts the following props:

- `as` (required): The HTML tag to use for the heading (h1, h2, h3, h4, h5, or h6)
- `children` (required): The text content of the heading
- `className` (optional): Additional classes to apply to the heading
- `size` (optional): The font size of the heading (xs, sm, base, lg, xl, 2xl, 3xl, 4xl)
- `weight` (optional): The font weight of the heading (normal, medium, semibold, bold, extrabold)
- `color` (optional): The color of the heading (foreground, card, popover, primary, secondary, accent, destructive, or zinc-50 to zinc-950)

All props except `as`, `children`, and `className` can be responsive, allowing you to specify different values for different screen sizes.

## Responsive Props

The Heading component supports responsive props for size, weight, and color. You can specify different values for different breakpoints:

```jsx
<Heading
  as="h2"
  size={{ base: 'xl', md: '2xl', lg: '3xl' }}
  weight={{ base: 'medium', md: 'bold' }}
  color={{ base: 'zinc-700', md: 'primary' }}
>
  Responsive Heading
</Heading>
```

## Examples

1. Basic usage:

```jsx
<Heading as="h1" size="4xl" weight="bold" color="primary">
  Main Title
</Heading>
```

2. Subtitle with custom color:

```jsx
<Heading as="h2" size="2xl" weight="medium" color="zinc-600">
  Subtitle with Custom Color
</Heading>
```

3. Responsive heading:

```jsx
<Heading as="h3" size={{ base: 'lg', md: 'xl', lg: '2xl' }} weight="semibold" color="secondary">
  Responsive Subtitle
</Heading>
```

## Accessibility Considerations

- Use appropriate heading levels (h1-h6) to maintain a logical document structure.
- Ensure sufficient color contrast for readability, especially when using custom colors.
- Avoid skipping heading levels (e.g., don't jump from h1 to h3 without using h2).

## Customization

The Heading component uses Tailwind CSS classes for styling. You can further customize its appearance by:

1. Modifying the `headingVariants` configuration in the component file.
2. Passing additional classes via the `className` prop.
3. Extending the Tailwind CSS configuration in your project.
