# Box Component

The Box component is a highly flexible and customizable layout primitive in our design system. It serves as a foundational building block for creating various UI layouts and can be used to apply spacing, background colors, borders, and other common CSS properties.

## Features

- Responsive props for layout customization
- Support for padding, margin, dimensions, and positioning
- Flexible display options (block, flex, grid)
- Background color and border customization
- Shadow and overflow control

## Usage

```jsx
import { Box } from '@squared/ui/box';

function MyComponent() {
  return (
    <Box
      padding={4}
      margin={[2, 4]}
      background="primary"
      borderRadius="md"
      display="flex"
      alignItems="center"
      justifyContent="center"
    >
      <p>Content goes here</p>
    </Box>
  );
}
```

## Props

The Box component accepts a wide range of props for customization. All props support responsive values using arrays (e.g., `[2, 4, 6, 8]` for different breakpoints).

- `padding`, `paddingX`, `paddingY`, `paddingTop`, `paddingBottom`, `paddingLeft`, `paddingRight`
- `margin`, `marginX`, `marginY`, `marginTop`, `marginBottom`, `marginLeft`, `marginRight`
- `display`: 'block' | 'inline' | 'inline-block' | 'flex' | 'inline-flex' | 'grid' | 'inline-grid'
- `flexDirection`, `flexWrap`, `flexGrow`, `flexShrink`
- `alignItems`, `justifyContent`
- `width`, `height`, `maxWidth`, `minWidth`
- `background`, `borderRadius`, `border`, `borderColor`
- `boxShadow`, `position`, `overflow`
- `className`: Additional CSS classes

For a complete list of props and their possible values, refer to the Box component's TypeScript definition.

## Examples

- Responsive Padding and Margin:

```jsx
<Box padding={[2, 4, 6, 8]} margin={[1, 2, 3, 4]}>
  Content with responsive spacing
</Box>
```

- Flex Container:

```jsx
<Box display="flex" flexDirection="row" alignItems="center" gap={4}>
  <Box>Item 1</Box>
  <Box>Item 2</Box>
  <Box>Item 3</Box>
</Box>
```

- Card-like Element:

```jsx
<Box
  padding={4}
  background="background"
  borderRadius="lg"
  boxShadow="md"
  width={['full', '3/4', '1/2']}
>
  <h2>Card Title</h2>
  <p>Card content goes here</p>
</Box>
```

The Box component's flexibility makes it a powerful tool for creating consistent layouts and UI elements throughout your application.
